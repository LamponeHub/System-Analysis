# 🧵 TextileCompliance AI: Интеллектуальный ассистент для швейного бизнеса

> **Статус:** MVP / Портфолио-кейс  
> **Роль:** Системный аналитик, Архитектор решений, Prompt Engineer  
> **Стек:** Python, LangChain, RAG, ChromaDB, Streamlit, LLM (Qwen/DeepSeek), Docs-as-Code

## 📖 О проекте

**TextileCompliance AI** — это прототип интеллектуальной системы поддержки принятия решений для малых швейных брендов и производств в РФ. Проект решает проблему высокой бюрократической нагрузки при подаче заявок на государственные гранты (ФРП, Минпромторг) и соблюдении нормативных требований (ГОСТ, ТР ТС) при выходе на маркетплейсы.

Система использует архитектуру **RAG (Retrieval-Augmented Generation)** для предоставления ответов, строго основанных на актуальных нормативных документах, исключая галлюцинации ИИ и обеспечивая ссылочную достоверность.

### 💡 Ценностное предложение
*   **Для бизнеса:** Сокращение времени подготовки документации с дней до часов; снижение риска отказа в грантах из-за формальных ошибок.
*   **Для отрасли:** Демократизация доступа к сложной нормативной базе для начинающих предпринимателей.
*   **Технологический подход:** Применение принципов **Docs-as-Code** для управления знаниями и версионирования логики работы ИИ.

---

## 🚀 Ключевые функции (MVP)

1.  **Грантовый консультант:** Генерация структуры заявки, чек-листов документов и черновиков обоснований на основе правил конкретных программ финансирования (2025-2026).
2.  **ГОСТ-аудитор:** Автоматическая проверка описаний товаров (состав, уход, маркировка) на соответствие актуальным ГОСТам и правилам модерации Wildberries/Ozon.
3.  **База знаний с цитированием:** Каждый ответ системы сопровождается прямой ссылкой на источник (документ, страница, пункт регламента).
4.  **Библиотека промптов:** Версионируемый набор мастер-промптов для различных сценариев использования, адаптированных под российскую специфику.
