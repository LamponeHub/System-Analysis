# Моделирование бизнес-процессов (BPMN)

## Процесс: "Подготовка заявки на грант с использованием AI"

Ниже представлено текстовое описание потока работ и код для генерации диаграммы в PlantUML.

### Описание шагов:
1.  **Start**: Пользователь инициирует процесс создания заявки.
2.  **Input Data**: Пользователь вводит параметры проекта (бюджет, оборудование, регион).
3.  **AI Retrieval**: Система ищет релевантные требования в базе знаний (RAG).
4.  **Gap Analysis**: Система сравнивает введенные данные с требованиями.
    *   *Decision*: Есть ли недостающие документы?
        *   **Yes**: Система генерирует список недостающего. Пользователь загружает файлы. (Loop back to Input/Data enrichment).
        *   **No**: Переход к генерации.
5.  **Draft Generation**: LLM генерирует черновик разделов заявки с цитированием источников.
6.  **Human Review**: Пользователь редактирует черновик, добавляет уникальные детали ("душа" проекта).
7.  **Final Check**: Повторная проверка на формальные ошибки.
8.  **Export**: Выгрузка итогового документа (PDF/DOCX).
9.  **End**: Заявка готова к подаче.

### Код диаграммы (PlantUML)

```plantuml
@startuml
start
:Пользователь: Ввод параметров проекта;
partition "Система (AI)" {
  :Поиск требований в RAG базе;
  :Сравнение данных с регламентом (Gap Analysis);
}
if (Есть недостающие данные?) then (Да)
  :Генерация чек-листа缺失ющих документов;
  :Пользователь: Загрузка дополнительных файлов;
  else (Нет)
endif
:Генерация черновика заявки (LLM);
:Пользователь: Редактирование и уточнение текста;
:Финальная автоматическая проверка;
:Экспорт в PDF/DOCX;
stop
@enduml
