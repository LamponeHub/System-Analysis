# Эфир: Осознанная Экосистема Управления Недвижимостью

## Философия
Проект реализует принцип неразделимости материального комфорта и душевного спокойствия. 
Система автоматически защищает право резидентов на тишину и чистый воздух, используя жесткие алгоритмические правила вместо человеческих эмоций.

## Принципы работы
1. **Zero Hallucination Policy**: Ответы генерируются только на основе файлов из `/docs/regulations`. Любая информация без ссылки на источник блокируется валидатором.
2. **Docs-as-Code**: Все изменения в правилах дома проходят через Git Flow с обязательным ревью.
3. **Silence by Default**: Система приоритизирует зоны тишины. Шум > 45 дБ после 23:00 триггерит автоматический протокол нарушения.

## Стек
- **LLM**: Qwen-2.5-7B-Instruct (локально, через Ollama/vLLM) — никаких внешних API.
- **Vector DB**: ChromaDB (embedded).
- **Backend**: Python (FastAPI).
- **IaC**: Docker Compose.
- **Process**: ITIL-based incident management.
