# ГОСТ 31319-2009 (Адаптированный для ЖК "Эфир")
## Предельно допустимые уровни шума

### 4. Общие требования
4.1. В жилых комнатах квартир эквивалентный уровень звука не должен превышать:
- Днем (07:00–23:00): **40 дБА**
- Ночью (23:00–07:00): **30 дБА**

### 5. Процедуры нарушения
5.1. При фиксации уровня шума > 45 дБА в ночное время система автоматически:
1. Фиксирует событие в логе (Git commit в ветку `incidents`).
2. Отправляет предупреждение нарушителю.
3. Блокирует доступ гостевых ключей в квартиру нарушителя до устранения причины.

> Примечание: Измерения проводятся датчиками класса 1. Субъективная оценка жильцов не является основанием для санкций без инструментального подтверждения.
