# ГОСТ 31319-2009: Шум в жилых помещениях (Адаптация для ЖК "Эфир")

## 1. Область применения
Настоящий стандарт устанавливает предельно допустимые уровни шума в жилых комнатах квартир, общих помещениях многоквартирных домов и на придомовой территории ЖК "Эфир".

## 2. Нормативные значения
### 2.1. Эквивалентный уровень звука (дБА)
В жилых комнатах квартир допустимые уровни шума составляют:
- **Дневное время (07:00 – 23:00):** не более **40 дБА**.
- **Ночное время (23:00 – 07:00):** не более **30 дБА**.

### 2.2. Максимальный уровень звука (дБА)
Максимальный уровень звука не должен превышать допустимый более чем на **15 дБА**:
- Днем: макс. **55 дБА**.
- Ночью: макс. **45 дБА**.

> **Примечание:** Превышение уровня 45 дБА в ночное время классифицируется как критическое нарушение режима тишины.

## 3. Процедуры реагирования (Регламент УК "Эфир")
При фиксации нарушения датчиками системы "Эфир":
1. **Автоматическая фиксация:** Создание инцидента в системе с меткой `CRITICAL_NOISE`.
2. **Первое предупреждение:** Автоматическая отправка Push-уведомления нарушителю со ссылкой на [ГОСТ 31319-2009, п. 2.1].
3. **Повторное нарушение (в течение 1 часа):**
   - Блокировка доступа гостевых ключей в квартиру нарушителя.
   - Уведомление дежурного администратора для выезда на место.
4. **Систематические нарушения (3 раза в месяц):** Инициирование процедуры выселения согласно договору найма/проживания.

## 4. Исключения
Действие стандарта не распространяется на:
- Аварийные работы по предотвращению стихийных бедствий.
- Работы, проводимые в рамках общедомовых мероприятий, согласованных за 3 суток до начала (не применимо к ночному времени).
