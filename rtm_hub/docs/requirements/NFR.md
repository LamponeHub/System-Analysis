# Non-Functional Requirements (NFR)

| Категория | Требование | Критерий приемки |
|-----------|-----------|------------------|
| Производительность | Время ответа API | < 200мс для 95% запросов |
| Доступность | Uptime | 99% в рабочее время |
| Безопасность | Аутентификация | JWT токены |
| Масштабируемость | Контейнеризация | Docker + Docker Compose |
| Документация | API Docs | Auto-generated Swagger UI |
| Совместимость | Браузеры | Chrome, Firefox, Safari (последние 2 версии) |
