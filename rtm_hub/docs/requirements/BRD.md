# Business Requirements Document (BRD)

## 1. Цель проекта
Создание легковесного инструмента для управления требованиями и построения матрицы трассируемости (RTM).

## 2. Бизнес-проблемы
- Отсутствие единого источника истины по требованиям
- Сложность отслеживания изменений
- Ручное ведение RTM в Excel

## 3. Бизнес-требования
| ID | Требование | Приоритет |
|----|-----------|-----------|
| BR-01 | Возможность создания требований | High |
| BR-02 | Возможность связывания требований | High |
| BR-03 | Экспорт RTM в Excel/PDF | Medium |
| BR-04 | Версионирование требований | Medium |
| BR-05 | Поиск и фильтрация | High |

## 4. Заинтересованные стороны
- Системные аналитики
- Менеджеры проектов
- Разработчики
- Тестировщики
