# 📋 RTM Hub - Documentation

## О проекте
**Requirements Traceability Hub** — инструмент для управления требованиями и построения матрицы трассируемости.

## Быстрый старт

```bash
# Клонировать репозиторий
git clone https://github.com/yourusername/rtm-hub.git
cd rtm-hub

# Запустить через Docker
docker-compose up -d

# Открыть приложение
http://localhost:8000

# Открыть документацию
http://localhost:8080

# Swagger UI
http://localhost:8000/docs
