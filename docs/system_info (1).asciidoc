== Назначение
Скрипт `system_info.py` собирает техническую информацию об операционной системе, оборудовании и среде выполнения.  
Предназначен для диагностики, аудита или логирования конфигурации системы.

== Требования

=== Обязательные компоненты
* Python 3.6+
* Стандартная библиотека Python:
  - `platform`
  - `socket`
  - `os`
  - `sys`
  - `shutil`
  - `datetime`

=== Опциональные зависимости
* link:https://pypi.org/project/psutil/[`psutil`] — для расширенной информации о CPU, RAM и диске.

Установка:
[source,shell]
----
pip install psutil
----

Без `psutil` скрипт продолжит работать, но с ограниченной детализацией.

== Собираемая информация

=== Базовая (без зависимостей)
- Операционная система (`platform.system()`)
- Версия ОС и релиз
- Архитектура (`machine`)
- Имя хоста и локальный IP-адрес
- Модель процессора (если доступна)
- Версия Python
- Текущий пользователь и рабочая директория

=== Расширенная (при наличии `psutil`)
- Количество физических и логических ядер CPU
- Максимальная частота процессора
- Объём оперативной памяти (всего, использовано, свободно)
- Процент загрузки RAM
- Информация о корневом диске (`/`):
  - Общий объём
  - Использовано / свободно
  - Процент заполнения
- Время последней загрузки системы

== Использование

[source,shell]
----
# Сохраните скрипт как system_info.py
wget https://example.com/system_info.py  # или создайте вручную

# (Опционально) установите psutil
pip install psutil

# Запустите
python system_info.py
----

== Ограничения и примечания

* IP-адрес определяется через `socket.gethostbyname(socket.gethostname())`.  
  В некоторых сетях (например, Docker, WSL2, корпоративные LAN) может возвращать `127.0.1.1` или `127.0.0.1`.
* На Linux `platform.processor()` часто возвращает пустую строку — это особенность ядра.
* Информация о диске относится только к корневому разделу (`/`). Для Windows — к `C:\`.
* Скрипт **не изменяет** систему — только читает данные.
* Работает на Windows, Linux и macOS.

== Безопасность
Скрипт не передаёт данные во внешние системы, не записывает логи и не требует повышенных привилегий.  
Может использоваться в защищённых средах.
