🔍 Диагностика и логи
Частые ошибки и решения
Ошибка
Причина
Решение
Bot token is invalid
Неверный токен
Проверьте BOT_TOKEN в .env, нет ли пробелов
Payment gateway error
Не настроены ключи
Заполните YOOKASSA_* переменные, включите тестовый режим
Бот не отвечает
Процесс упал
systemctl status vanilla-bot или docker-compose ps
Не приходят уведомления
Неверный ADMIN_CHAT_ID
Узнайте свой ID в @userinfobot, проверьте, что бот не заблокирован
ModuleNotFoundError
Запуск не из корня
Запускайте python main.py из папки vanilla_bot/
Включение отладочных логов
В .env добавьте:
env
1
