[[введение]]
== Введение
Документ описывает требования к функционалу корзины покупок для интернет-магазина «Петрушка Зеленая».

[[цели]]
=== Цели
* Предоставить пользователям интуитивно понятный интерфейс для управления выбранными товарами
* Обеспечить корректное соблюдение бизнес-ограничений
* Зафиксировать цену товара на момент добавления в корзину
* Интегрировать механизм рекомендаций для увеличения среднего чека

[[контекст]]
=== Контекст
Корзина является обязательным промежуточным этапом между выбором товара и оформлением заказа.

[[требования]]
== Функциональные требования

[[добавление-товара]]
=== 1. Добавление товара в корзину

[[добавление-основные]]
==== 1.1. Основная логика
* Пользователь может добавить в корзину от **1 до 10 единиц** одного товара за одно действие.
* Цена товара *фиксируется* на момент его добавления в корзину и сохраняется неизменной до момента оформления заказа или удаления товара.

[[добавление-ограничения]]
==== 1.2. Ограничения корзины
* Максимальное количество **разных товаров (наименований)** в корзине: **5**
* Максимальное **общее количество единиц товаров** в корзине: **20**

[[добавление-обработка-ошибок]]
==== 1.3. Обработка ошибок при добавлении
При попытке добавить товар, превышающий какой-либо из лимитов, система должна предотвратить добавление и показать соответствующее сообщение:

|===
| Нарушенный лимит | Сообщение пользователю
| Максимум единиц одного товара (10) | «Максимальное количество одного товара — 10 шт.»
| Максимум разных товаров (5) | «В корзине не может быть более 5 разных товаров»
| Максимум всех товаров (20) | «Превышено максимальное количество товаров в корзине (20 шт.)»
|===

*Приоритет проверки:* система должна проверять лимиты в следующем порядке: лимит одного товара → лимит разных товаров → общий лимит.

[[управление-товарами]]
=== 2. Управление товарами в корзине

[[управление-изменение-количества]]
==== 2.1. Изменение количества
Пользователь может увеличивать или уменьшать количество для каждого товара в корзине через:
* Поле ввода с ручным редактированием
* Кнопки «+» (увеличить на 1) и «–» (уменьшить на 1)

Минимальное значение для товара в корзине — **1 единица**.

[[управление-удаление]]
==== 2.2. Удаление товара
* Для полного удаления товара используется отдельная кнопка «Удалить» (иконка корзины/крестик).
* При нажатии кнопки «Удалить» система отображает диалог подтверждения: «Удалить [Название товара] из корзины?» с кнопками «Отмена» и «Удалить».

[[управление-очистка]]
==== 2.3. Очистка корзины
* В интерфейсе корзины должна присутствовать кнопка «Очистить корзину».
* При нажатии кнопки система отображает диалог подтверждения: «Удалить все товары из корзины?» с кнопками «Отмена» и «Очистить».

[[отображение]]
=== 3. Отображение и расчеты

[[отображение-состав]]
==== 3.1. Состав корзины
Для каждого товара в списке отображаются следующие данные:
* Название товара (ссылка на карточку товара)
* Изображение товара (превью)
* Фиксированная цена за единицу (руб.)
* Элемент управления количеством (согласно п. 2.1)
* Общая стоимость позиции: `цена за единицу × количество` (руб.)
* Кнопка удаления (согласно п. 2.2)

[[отображение-итоги]]
==== 3.2. Итоговая информация
Внизу списка товаров отображается блок с расчетами:
* **Общая стоимость товаров:** сумма всех `общая стоимость позиции`
* **Скидка:** применяемая скидка по промокоду/акции (отображается только при наличии)
* **Стоимость доставки:** рассчитывается на этапе оформления заказа
* **К оплате (итог):** `Общая стоимость товаров – Скидка + Стоимость доставки`

[[отображение-рекомендации]]
==== 3.3. Блок рекомендаций
* В интерфейсе корзины должно быть предусмотрено место для блока «С этим товаром покупают» или «Рекомендуем».
* Данные для блока запрашиваются из внешнего сервиса рекомендаций.
* *Примечание для маркетинга:* логика формирования и расписания показа рекомендаций управляется отдельной системой и не входит в данный ТЗ.

[[взаимодействие-складом]]
=== 4. Взаимодействие с каталогом и складом

[[взаимодействие-остатки]]
==== 4.1. Проверка доступности
При следующих событиях система должна проверить актуальность корзины:
1. При открытии страницы корзины.
2. При переходе к оформлению заказа.

Если обнаружены расхождения, пользователю отображается уведомление: «Состав вашей корзины изменился».

[[взаимодействие-сценарии]]
==== 4.2. Сценарии обработки изменений
|===
| Ситуация | Действие системы
| Товар удален из каталога | Позиция помечается как «Товар более недоступен». Предлагается кнопка «Удалить».
| Доступное количество на складе < количества в корзине | Отображается сообщение: «Доступно только [N] шт.». Поле количества автоматически уменьшается до доступного значения, пользователь может уменьшить его далее или удалить товар.
|===

[[нефункциональные]]
== Нефункциональные требования

[[производительность]]
=== 5.1. Производительность
* Обновление количества товара в корзине должно происходить без перезагрузки страницы (AJAX).
* Задержка ответа на действие пользователя (добавление, изменение количества) не должна превышать 500 мс.

[[совместимость]]
=== 5.2. Совместимость
Функционал должен корректно работать в последних версиях браузеров:
* Google Chrome
* Mozilla Firefox
* Safari
* Yandex Browser

[[открытые-вопросы]]
== Открытые вопросы для уточнения заказчиком

1. *Резервирование товара:* Требуется ли резервировать товар на складе в момент добавления в корзину или только на этапе оформления/оплаты заказа?
2. *Срок хранения корзины:* Каков срок жизни корзины для неавторизованного и авторизованного пользователя? Должна ли корзина сохраняться между сессиями?
3. *Интеграция с промокодами:* Детальная логика применения и валидации промокодов в корзине будет описана в отдельном ТЗ?
4. *Мобильная версия:* Требуется ли адаптивный дизайн корзины под мобильные устройства в рамках данной задачи?
